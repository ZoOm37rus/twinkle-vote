# Политика конфиденциальности Твинкл

Дата: 20 октября 2026 года. Версия расширения: 0.1.0.

Твинкл помогает пользователю организовать ручное голосование на WARGM.

Расширение сохраняет в локальном хранилище браузера названия и ссылки серверов, время открытия страниц, пользовательские отметки, время следующих напоминаний, настройки и последние 80 записей истории. Эти сведения нужны для списка серверов и напоминаний.

Разработчик не получает эти данные. У расширения нет своего сервера, аналитики, рекламы, отслеживания и передачи данных третьим лицам. Автоматическая синхронизация между устройствами не выполняется.

По отдельному действию пользователя список экспортируется в локальный файл. В него включаются только названия и ссылки серверов. При импорте существующие записи не заменяются.

Когда пользователь нажимает кнопку открытия сервера, браузер открывает страницу WARGM. Сайт получает обычное обращение браузера и обрабатывает данные по своей политике. Расширение не читает содержимое страницы, cookie, пароли, историю браузера и не отправляет голоса.

Разрешения:

- `storage`: локальное хранение списка и настроек.
- `alarms`: расписание напоминаний.
- `notifications`: необязательное разрешение, запрашивается только при включении уведомлений.

Серверы удаляются через интерфейс, история очищается отдельно. При удалении расширения его локальные данные удаляются браузером. Ранее экспортированные файлы пользователь удаляет самостоятельно.

Разработчик не продаёт пользовательские данные, не использует их для рекламы, кредитных решений или целей, не связанных с заявленной функцией расширения.

После публикации публичного репозитория вопросы и сообщения об ошибках можно направлять через его раздел Issues. До размещения карточки магазина издатель должен указать действующую публичную ссылку поддержки.

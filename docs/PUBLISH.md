# Размещение исходников и расширения

Исходники и выпуски публикуются в https://github.com/ZoOm37rus/twinkle-vote. В Chrome Web Store расширение ещё не опубликовано.

## GitHub

Рекомендуемое имя публичного репозитория: `twinkle-vote`.

1. Создайте пустой публичный репозиторий в нужном аккаунте или организации.
2. Загрузите содержимое `Twinkle-0.2.0-source.zip` либо отправьте локальный репозиторий.
3. Убедитесь, что видны README, LICENSE, PRIVACY, код расширения, тесты и сборочный сценарий.
4. Включите Issues для обращений пользователей.
5. Создайте выпуск `v0.2.0` и приложите Chrome ZIP и SHA256SUMS.txt.
6. Включите GitHub Pages для папки `docs` на ветке `main`. Готовая политика находится в `docs/privacy.html`. В карточку Google вставьте реально открывающийся публичный URL этой страницы.

Не загружайте `.tools`, `node_modules`, тестовые профили, `.git`, личные списки серверов, ключи и данные входа. Сборочный сценарий исключает служебные папки.

Если GitHub подключён к Codex, доступ можно использовать для загрузки в выбранный репозиторий. На момент подготовки проекта подключение не было авторизовано.

## Chrome Web Store

1. Войдите в аккаунт издателя Chrome Web Store. Если аккаунта нет, зарегистрируйте его и выполните требования кабинета, включая регистрационный платёж.
2. Заполните сведения об издателе и публичный адрес поддержки.
3. Создайте новое расширение и загрузите `Twinkle-0.2.0-chrome.zip`.
4. Возьмите тексты из `STORE_LISTING.md`.
5. Добавьте иконку 128×128, скриншот 1280×800 и малое рекламное изображение 440×280 из `docs/assets`.
6. Укажите действующие ссылки на исходники, поддержку и политику конфиденциальности.
7. Заполните разделы назначения, разрешений и использования данных по реальному поведению версии.
8. Проверьте расширение вручную в обычном Chrome и отправьте на проверку.

Модерация выполняется Google. Подготовленный ZIP не означает, что расширение уже принято или опубликовано.

## До отправки

- Уточнить владельца репозитория и издателя.
- Указать публичную поддержку и опубликовать политику.
- Проверить доставку уведомлений в обычном Chrome и Windows.
- Проверить голосование пользователем на реальном WARGM. Расширение не подтверждает результат самостоятельно.
- Добавить реальные ссылки на ваши серверы вручную либо передать игрокам экспортированный список.

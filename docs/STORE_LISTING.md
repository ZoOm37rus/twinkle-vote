# Карточка Chrome Web Store

## Название

Твинкл: помощник голосования

## Краткое описание

Серверы WARGM в одном месте, напоминания через 16 часов и переход к ручному голосованию.

## Полное описание

Поддерживать любимые серверы проще, когда всё собрано в одном месте.

Добавьте до 19 серверов WARGM и включите напоминания. Твинкл поможет по очереди открыть страницы и не забыть о следующем голосовании.

Что умеет Твинкл:

- Добавляет сразу несколько серверов из списка ссылок.
- Открывает следующий сервер по вашему нажатию.
- Напоминает через 16 часов после вашей отметки «Я проголосовал».
- Позволяет отложить напоминание на час или поставить всё на паузу.
- Сохраняет список в файл для переноса на другой компьютер.
- Показывает понятную историю ваших действий.

Голосование подтверждаете вы на сайте WARGM. Расширение не отправляет голоса автоматически и не проверяет, засчитаны ли они. Доступность голосования определяет сайт.

Твинкл не открывает вкладки без вашего нажатия. Список и настройки хранятся только в вашем браузере. Нет рекламы и аналитики. Уведомления включаются отдельно, по вашему желанию.

Если браузер закрыт или компьютер спит, напоминание может прийти позже.

Твинкл не является официальным расширением WARGM.

## Единственная цель

Организация пользовательского списка серверов WARGM и локальных напоминаний для ручного голосования.

## Обоснование разрешений

storage: сохранение списка серверов, настроек, пользовательских отметок и ограниченной истории на устройстве.

alarms: обновление напоминаний и счётчика после истечения пользовательского интервала.

notifications: необязательные системные уведомления о серверах, ожидающих ручного голосования. Разрешение запрашивается только при включении этой функции.

Удалённый код не используется.

## Данные и конфиденциальность

Перед отправкой формы издатель должен сверить текущие вопросы Google с `PRIVACY.md`. Список и отметки хранятся локально, разработчику не передаются. Не заявлять, что расширение вообще ничего не сохраняет.

## Инструкция для проверяющего

1. Установить расширение и открыть его через значок.
2. Добавить ссылку на существующий сервер WARGM.
3. Включить напоминания.
4. Нажать «Открыть WARGM». Откроется одна страница только после нажатия.
5. Самостоятельно пройти голосование на сайте, если оно доступно.
6. Вернуться в расширение и нажать «Я проголосовал». Появится время через 16 часов.
7. Проверить отмену отметки, откладывание на час и паузу.

Основные возможности списка, экспорта и напоминаний не требуют аккаунта WARGM. Учётная запись может требоваться самим сайтом для голосования.

# Проверка версии 0.2.0

Дата: 20 октября 2026 года.

## Выполнено

- 45 проверок логики на Node.js.
- Старый браузерный сценарий списка, импорта, экспорта, ручных отметок, отмены, откладывания, уведомлений и сохранения после перезапуска.
- Новый сценарий прохода в отдельном Chromium 156.0.8078.4 на локальных страницах с адресами WARGM.
- Две кнопки, 15 основных серверов и 4 Сталкера. Группа сохраняется после переименования сервера.
- Ожидание кнопки, отсутствие автоматически отправленных кликов, настоящий тестовый клик через браузер, обновление страницы и таймер 15ч. 60м.
- Переход в той же вкладке, запись результата один раз, сохранение времени таймера.
- Синтетический клик страницы не считается ручным подтверждением. Уже показанный таймер пропускает сервер без записи нового голоса.
- Таймер в соседней карточке не учитывается. Ошибки и неподходящий текст не подтверждают голос.
- Отклоняются сообщения от другой вкладки, фрейма, сайта, старого документа и старого прохода.
- Закрытие вкладки и запуск браузера ставят проход на паузу. Ошибка перехода сохраняет записанный результат; продолжение идёт со следующего сервера.
- Завершение четырёх серверов Сталкера возвращает в список и не начинает основную группу.
- Кнопки пропуска и остановки, интерфейс 390 px без горизонтальной прокрутки.
- Визуально просмотрены меню расширения и панель на тестовой странице голосования.

## Основания для распознавания

Публичная страница https://wargm.ru/server/71046/votes показывает карточку с заголовком «Голосование» и её .card-footer. Публичный сценарий сайта активирует .voting и назначает data-send=/server/vote. Предоставленные пользователем скриншоты показывают последовательность «АКТИВАЦИЯ», «ГОЛОСОВАТЬ», затем таймер 15ч. 60м. после обновления страницы. Полная разметка авторизованного таймера в живом аккаунте пока не исследована.

Наблюдатель читает только видимый таймер кнопки внутри этой карточки. Настоящий клик запоминается до обновления страницы. Если таймер появился в течение 10 минут после клика, записывается результат по таймеру; без клика записывается только оставшееся время. Это наблюдение за страницей, не независимая проверка серверного учёта голосов или бонусов.

## Не выполнено

- Реальное голосование с авторизацией на WARGM и проверка начисления бонусов.
- Реальное прохождение CAPTCHA и других проверок сайта.
- Доставка уведомлений Windows, длительное ожидание 16 часов и модерация Chrome Web Store.

Новый браузерный тест перехватывает все внешние запросы и возвращает локальную имитацию карточки. Он проверяет взаимодействие расширения, вкладок и хранения, но не гарантирует совместимость с неизвестной разметкой авторизованного WARGM. При несовпадении расширение остаётся на странице, результат не записывается.

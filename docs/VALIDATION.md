# Проверка версии 0.1.1

Дата: 20 октября 2026 года.

## Выполнено

- 19 уникальных ссылок Twinkle Play из публичного списка проекта WARGM.
- Первичная установка с готовыми 19 серверами в отдельном профиле Chromium.
- Обновление без сброса существующих отметок и названий, без дубликатов.
- Удалённые серверы не восстанавливаются после повторного запуска.
- Существующий список не превышает 19 записей при обновлении.

- 34 автоматических проверок логики на Node.js 24.19.0.
- Загрузка Manifest V3 в отдельном профиле Chromium 156.0.8078.4.
- Добавление нескольких серверов через реальный интерфейс.
- Проверка запроса открытия одного сервера по нажатию.
- Ручная отметка и точный интервал 57 600 000 мс.
- Отмена отметки и перенос напоминания на час.
- Экспорт файла и обратный импорт без дубликатов.
- Отклонение ссылок на посторонние домены.
- Проверка отображения пользовательского названия как текста, а не HTML.
- Удаление с подтверждением и остановка таймеров на паузе.
- Закрытие браузера и повторный запуск с сохранением списка и паузы.
- Визуальный просмотр широкого интерфейса и узкого окна 390 px.
- Отсутствие ошибок JavaScript страницы в проверенном сценарии.

Проверки фоновой части дополнительно покрывают одновременное добавление записей, отказ открытия вкладки, повторные напоминания, отказ и отзыв разрешения уведомлений, отложенное напоминание и отказ команд от посторонней страницы.

Браузерный тест заменяет адрес новой вкладки на `about:blank` внутри тестового процесса и отдельно проверяет исходный адрес. Это проверка интерфейса, обмена сообщениями, вызова браузерного API и хранения. Это не проверка реального голосования на WARGM.

В первой попытке теста ожидание новой вкладки средствами Playwright завершилось по тайм-ауту. В окончательном тесте вкладка проверяется через браузерный API с подменой адреса. Сбой не воспроизводился как ошибка самого интерфейса.

## Не выполнено

- Ручное голосование с настоящим аккаунтом на WARGM.
- Доставка системных уведомлений в обычном Chrome и Windows.
- Непрерывная проверка в течение 16 часов. Отсчёт проверен программно.
- Проверка Chrome Web Store и публикация.
- Выкладка на GitHub: подключённый инструмент вернул отсутствие авторизации.

Образцы серверов на скриншотах демонстрационные. В поставляемом расширении нет заранее заполненного списка.

## Повторение

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
node scripts/store_assets.mjs
python scripts/build.py
```

Браузерный отчёт создаётся в `test-results/browser-report.json`. Тестовые данные и профили не включаются в поставку.
